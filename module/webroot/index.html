        Logs

          Stealth tiers

          A tier is a ceiling on how loud the hooks may be. Raise it for one app only when its log says a surface needs it.

          max
          Pointer rewrites in data pages, DEX patched while ART verifies it, file work outside the process. No executable byte of the app changes.
          balanced
          Adds inline code hooks and pattern scanning. A checksum of the hooked library detects it.
          compat
          Adds libc hooks and the ArtMethod fallback. Standard Xposed checks detect it.

          Proxy redirect

          Leave it empty for apps that honour the system proxy. Flutter and most native code ignore that setting; for those, enter your proxy as ip:port.

          What it does
          Sends this app's TCP ports 80 and 443 to the proxy and blocks HTTP/3, from outside the app. Nothing is added to the app.
          What the proxy needs
          The app talks straight to it, with no proxy-style request, so the listener must accept direct HTTP and TLS and take the host from the Host header or the TLS server name. In Burp that is "Support invisible proxying" on the listener.
          While it is on
          If the proxy is unreachable the app has no HTTP or HTTPS. Clear the field, save and reopen the app to turn it off.

          Coverage lines

          reachable=yes
          The surface is hooked.
          present=yes reachable=no
          The app has the surface and the tier blocks it. Set this app's tier to the required_tier shown on the line.
          present=no
          Normal: the app does not ship that library.
