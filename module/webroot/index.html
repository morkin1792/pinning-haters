pinning-haters

Zygisk TLS pinning bypass. Config: /data/adb/pinning_haters/config.json

No shell bridge

This WebUI needs the KernelSU or APatch manager (ksu.exec is missing). Magisk Manager has no WebUI; edit the config over adb instead, starting from the example config in the repo:

adb shell su -c 'mkdir -p /data/adb/pinning_haters'
adb push examples/config.example.json /data/local/tmp/ph.json
adb shell su -c 'cp /data/local/tmp/ph.json /data/adb/pinning_haters/config.json; chmod 600 /data/adb/pinning_haters/config.json; rm /data/local/tmp/ph.json'
adb shell su -c 'cat /data/adb/pinning_haters/config.json'

Then put your package names under "packages"; the companion re-reads the file on every app launch. Note that Magisk's built-in Zygisk does not hide module libraries; prefer a host that does if stealth matters.

Global stealth tier: max

Change the global tier to ? Every package without its own override gets louder hooks.
  • max (default): GOT slots in system libraries, DEX patch at verification time, companion-side oat eviction. Zero modified executable bytes in the app.
  • balanced: adds inline .text hooks and pattern scanning. A text CRC of the hooked library detects it.
  • compat: adds libc hooks and the ArtMethod fallback. Standard Xposed checks catch it.
